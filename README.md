Проект "база данных меломана" для курсовой работы. «Государственный университет морского и речного флота имени адмирала С.О. Макарова»

Перед использованием нужно установить Node.js LTS
Далее запустить терминал в корневой директории и выполнить следующие команды:
npm install
npm start

Веб-приложение будет доступно по адресу localhost:3000
