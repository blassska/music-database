# Проект "база данных меломана" для курсовой работы по дисциплине "Технологии программирования". ВУЗ - «Государственный университет морского и речного флота имени адмирала С.О. Макарова»

Перед использованием нужно скачать и установить Node.js LTS - https://nodejs.org/en/download

Далее запустить терминал в корневой директории и выполнить следующие команды:

`npm install`

`npm start`

Веб-приложение будет доступно по адресу <u>localhost:3000</u>

*P.S. Проект рассчитан на ознакомление с кодом веб-приложения, а также его тестированием в рамках защиты или написания иной работы.*
